# El Semillero — Coastal Fisheries Map

Interactive map of Chile's AMERB coastal fishery management zones.

**Live:** https://simonrab.github.io/ChileCoastal/

## What it shows

- AMERB polygons colour-coded by zone type (Coastal / Urban / Industrial)
- Benthic species filter (loco, erizo, lapa, etc.)
- MMA heavy metal monitoring stations with 30-year trend data (Cu, Pb, Cd, Hg)
- Reference layers — ports, urban limits, marine protected areas, Capital Azul TURF reserves
- EN / ES toggle

## Stack
React · TypeScript · Vite · Tailwind · Leaflet · GitHub Pages

## Data
SERNAPESCA · MMA Líneas de Base Públicas · DOP · MINVU · CONAF/SBAP
